# Python Calculator & Unit Converter

## About the Project
This is a beginner-friendly Python project that performs basic mathematical calculations and unit conversions using a simple menu-driven program.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
- Kilometers to Miles conversion
- Celsius to Fahrenheit conversion
- Invalid input handling
- Exit option

## Technologies Used
- Python 3
- Visual Studio Code (VS Code)

## How to Run the Project
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the `project1.py` file.
5. Select an option from the menu and enter the required values.
